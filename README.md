# knn-classification
# K-Nearest Neighbors (KNN) Classification

## Objective

To implement and understand KNN for classification problems.

## Tools Used

* Python
* Scikit-learn
* Pandas
* Matplotlib

## Dataset

Iris Dataset from sklearn

## Steps Performed

1. Loaded the Iris dataset
2. Split data into training and testing sets
3. Normalized the features
4. Trained KNN classifier
5. Tested different K values
6. Evaluated accuracy and confusion matrix
7. Plotted K vs Accuracy graph

## Results

* KNN successfully classified the flower species
* Accuracy changed based on the value of K
* Best accuracy was achieved for an optimal K value

## Conclusion

KNN is a simple and effective classification algorithm that depends heavily on distance and the choice of K.
